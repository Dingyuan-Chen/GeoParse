# GeoParse: Bridging the attribute-to-category gap for explainable fine-grained greenhouse recognition based on a geometric concept parsing framework from high-resolution remote sensing imagery

## Installation 
For installation and other package requirements, please follow the instructions detailed in [INSTALL.md](docs/INSTALL.md). 

## Training and Evaluation
```bash
# seed=1
bash scripts/geoparse/train_and_test_geoparse.sh imagenet 1

# seed=2
bash scripts/geoparse/train_and_test_geoparse.sh imagenet 2

# seed=3
bash scripts/geoparse/train_and_test_geoparse.sh imagenet 3
```
